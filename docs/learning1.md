# 01. Variable and Data Type in Cangjie language

## Variable (Immutable vs Mutable)
for immutable variable we use `let`. In the other hand, we use `var` for mutable variable.

```cangjie
let name: String = "MyName"     // can not be changed (immutable)
var score: Int64 = 90           // can be changed (mutable)
score = 95;
